# Dependency Map

## Core Frameworks
- **Next.js (16.2.6):** Main application framework (Server and Client).
- **React (19.2.4):** UI library.
- **Mongoose (9.6.2):** MongoDB Object Data Modeling (ODM).

## Utility Libraries
- **TailwindCSS / tailwind-merge:** Styling and class management.
- **Framer Motion:** UI animations.
- **Zod:** Schema validation for API payloads.
- **SWR:** Client-side data fetching and state caching.
- **dnd-kit:** Drag-and-drop functionality for UI components.

## Security & Authentication
- **bcryptjs:** Password hashing.
- **jsonwebtoken / jose:** JWT generation and validation (Edge compatible).
- **speakeasy / qrcode:** 2FA generation.

## Real-time & External Communication
- **Pusher / Pusher-js:** WebSocket real-time event broadcasting.
- **Nodemailer:** Email sending service.

## Data Processing
- **exceljs / xlsx:** Handling Batch imports and exports.

## External Services dependency
- **MongoDB Atlas:** Main database.
- **Pusher Cloud:** Real-time infrastructure.
- **SMTP Provider:** For outgoing email notifications.
